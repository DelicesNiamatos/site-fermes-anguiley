# Identité officielle — Fermes Anguiley

## Logo officiel

Le fichier `assets/logo.svg` constitue le logo officiel web de la marque Fermes Anguiley, dérivé du logo source joint le 9 août 2026.

Règles d’usage :
- ne pas recadrer, déformer, recoloriser ou réinterpréter le logo ;
- conserver son intégrité visuelle ;
- utiliser ce fichier pour l’en-tête, le favicon et les pages web publiées ;
- texte alternatif recommandé : `Logo officiel Fermes Anguiley — héritage Mpogwe, terre natale, savoir-faire durable`.

Date de consécration comme logo officiel : 9 août 2026.
