# Les Fermes Anguiley Gabon SARL

Site public statique haute performance pour GitHub Pages.

## Déploiement

Le site est conçu pour GitHub Pages avec déploiement automatique via GitHub Actions.

- Source : `main`
- Workflow : `.github/workflows/deploy.yml`
- URL cible : `https://delicesniamatos.github.io/site-fermes-anguiley/`

## Qualité

- HTML/CSS statique, sans framework lourd
- Logo SVG intégré
- Système visuel Organic : crème, terracotta, sauge
- SEO de base : meta description, Open Graph, JSON-LD, sitemap, robots
- Fichier `.nojekyll` pour éviter les transformations Jekyll
- Page `404.html` avec redirection vers l’accueil
- Responsive mobile/tablette/desktop
